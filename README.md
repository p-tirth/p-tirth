### Now

- **[VoxDesk](https://github.com/p-tirth/voxdesk-server)**: a voice support agent for small businesses, built on Pipecat (STT → LLM → TTS). It looks up orders and answers from the store's own policy docs. When it can't help, it hands the call to a human. The eval suite runs in CI, and the latency scorecard publishes the misses too. Web client: [voxdesk-client](https://github.com/p-tirth/voxdesk-client).
- **Pipecat [#5501](https://github.com/pipecat-ai/pipecat/pull/5501)**: adds a Sarvam HTTP speech-to-text service, a REST sibling of the existing WebSocket one for when you only need to transcribe finished clips. Open, waiting on review.
